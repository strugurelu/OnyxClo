# Backend privado

Esta carpeta concentra lo privado del proyecto.

## Incluye
- `src/server.js`: API privada básica con endpoints de salud y configuración.
- `.env.example`: variables privadas requeridas.
- `private/`: carpeta reservada para archivos sensibles locales (no versionados).

## Uso local
```bash
cd backend
cp .env.example .env
npm install
npm run dev
```
